# ResearchCitationObjects
This is the repository where the metadata standard for Research Citation Objects (RCOs) is hosted. Here, you will find the minimum requirements and best practices for the DataCite and Schema.org JSON-LD metadata. This repository is managed by the chairs of the RDA Interest Group on Complex Citation Implementation (https://www.rd-alliance.org/groups/complex-citation-implementation-interest-group-cci-ig). 

## Contribution Guidelines
Please start by posting an issue. Multiple issue types are expected, such as:
- Discuss adding your Schema.org JSON-LD and the associated DataCite JSON to the repository. Contributors are expected to use the validation resources described in the JSON-LD folder to validate the contributed files.
- Discuss a current or new best practice or recommendation concerning the metadata.
- Ask a question about which Schema.org metadata field is useful for a given use case. Please take a look at the examples before opening an issue.
