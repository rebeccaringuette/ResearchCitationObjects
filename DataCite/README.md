DataCite JSON is one of two metadata formats required to create DataCite DOIs, the correct persistent identifier choice for RCOs. This choice enables citations to the RCO to progress correctly through the citation pipelines already implemented internationally. The equivalent metadata in XML is also permitted. The Schema.org JSON-LD metadata should be created first, and then the standard software should be used to automatically create this metadata.

This folder contains the corresponding DataCite JSON for each Schema.org JSON-LD example in this repository, which is to be used as a routine validation test for the metadata conversion software. In the future, the DataCite metadata conversion API will be preferred over custom software once known issues in that infrastructure are resolved.
